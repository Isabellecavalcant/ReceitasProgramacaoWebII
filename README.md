# Receitas de Programação Web II

Repositório com as atividades das receitas 5, 6, 7 e 8 da disciplina de Programação Web II. Cada receita está em uma pasta separada. A [página principal](index.html) reúne os links para todas elas.

## Receitas

- [Receita 5](receita5/) — arrow functions, callbacks, listas e links.
- [Receita 6](receita6/) — objetos JavaScript e tabelas com colunas configuráveis.
- [Receita 7](receita7/) — consulta à API JSONPlaceholder com `fetch` e `async/await`.
- [Receita 8](receita8/) — consulta à mesma API com `Promise`, `then` e `catch`.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- [JSONPlaceholder](https://jsonplaceholder.typicode.com/) nas receitas 7 e 8

## Como executar

No terminal, dentro da pasta do repositório, execute:

```bash
python3 -m http.server 8000
```

Depois, acesse [http://localhost:8000/](http://localhost:8000/) e escolha uma receita na página principal. As receitas 7 e 8 precisam de conexão com a internet para consultar a API.
